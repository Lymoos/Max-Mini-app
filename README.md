# Помощник — миниапп для MAX

Фронтенд: React + Vite (`frontend`). Бэкенд: Go + PostgreSQL (`backend`).

## Запуск

```bash
docker compose up -d
```

```bash
cd backend && cp .env.example .env
```

Заполнить в `backend/.env` ключ `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` (без них всё работает, но без YandexGPT).

Один раз загрузить аптеки, магазины, поликлиники и соцпомощь Москвы и Казани из OpenStreetMap (несколько минут, можно указать только нужные виды: `go run . import clinic social`):

```bash
cd backend && go run . import
```

```bash
cd backend && go run .
```

```bash
cd frontend && npm install && npm run dev
```

Перед показом можно обновить акции, чтобы даты были свежими: `go run . promos`.

Если основной сервер Overpass не отвечает, можно указать зеркало в `OVERPASS_URL`
(например, `https://maps.mail.ru/osm/tools/overpass/api/interpreter`).

## Поиск на главной

Запрос сначала разбирают правила и нечёткий поиск (опечатки, английская раскладка), YandexGPT — только если они не справились.
Под поиском появляется короткий ответ «что можно сделать» и кнопка перехода:
лекарство или товар с ценами рядом, аптеки и магазины, запись к врачу нужной специальности
(«нужен кардиолог», «к врачу по давлению» — сразу своя поликлиника с кардиологами), соцпомощь, конкретная льгота
(«компенсация за капремонт»), инструкция («как увеличить шрифт»), профиль и задача с временем
(«напомни выпить таблетку в 9») — её добавляют только после нажатия «Добавить».

Ответ ИИ — строгий JSON, каждое значение сверяется со справочниками, выдуманное отбрасывается.
Лечение приложение не назначает: на «что выпить от давления» — раздел лекарств и совет обратиться к врачу,
препарат показывается, только если человек назвал его сам.

## Рецепт по фото

Иконка камеры слева от поиска сразу открывает выбор фото. Приложение читает рецепт, показывает найденные лекарства
с дозировкой, и одной кнопкой список становится задачей «Купить в аптеке» с пунктами, которые можно отмечать.
Фото нигде не сохраняется.

Текст читается бесплатно на своём сервере, платный Yandex Vision подключается, только если бесплатное не справилось:

1. фото — программой Tesseract, PDF электронного рецепта — `pdftotext`;
2. если ничего не нашлось и задан ключ Yandex — Yandex Vision OCR (обычная модель, потом модель для рукописного текста).

Лекарства из справочника находят правила, остальное выписывает YandexGPT — только то, что написано в тексте рецепта.

Бесплатные программы нужно поставить на сервер (без них работает только Yandex Vision):

```bash
sudo apt install tesseract-ocr tesseract-ocr-rus poppler-utils
```

Для Yandex Vision у сервисного аккаунта ключа нужна роль `ai.vision.user`.
Печатные и электронные рецепты читаются хорошо, рукописные — только разборчивые.

## Данные

Координаты, названия и адреса аптек и магазинов — настоящие, из OpenStreetMap.
Телефоны организаций соцпомощи и клиник — из OpenStreetMap, где они указаны.
Рейтинги, цены, акции, скидки в день рождения и врачи в поликлиниках — демонстрационные (в базе `source = 'demo'`),
их нужно заменить на реальные источники перед запуском для пользователей.

Записаться к врачу прямо в приложении нельзя: у ЕМИАС и Госуслуг нет открытого API.
Приложение показывает поликлинику по прописке, врачей и открывает официальный портал записи своего региона.

## Бот MAX

Бот работает в том же Go-сервере (long polling, публичный адрес для него не нужен) и включается, когда задан токен.

1. Создайте бота на платформе MAX для бизнеса, скопируйте токен.
2. В `backend/.env`: `MAX_BOT_TOKEN=…` и `MAX_BOT_NAME=…` (публичное имя бота — нужно кнопке «Открыть помощника»).
3. API MAX работает на сертификате Минцифры. Скачайте корневой сертификат Russian Trusted Root CA
   (PEM) с официальной страницы https://www.gosuslugi.ru/crt и укажите путь в `MAX_CA_FILE`.
   Сертификат добавляется только в HTTP-клиент бота, системные настройки не меняются.
4. В настройках бота укажите адрес миниаппа (HTTPS).

Что умеет бот:
- на название лекарства или продукта отвечает тремя лучшими местами рядом с ценами и кнопкой, которая открывает миниапп сразу на этом товаре (`startapp=med_…` / `prod_…`);
- понимает те же запросы, что и поиск в миниаппе: врач по специальности (`doctor_cardiologist`), льгота (`benefit_overhaul`),
  инструкция (`guide_font`), профиль (`profile`), аптеки, магазины и соцпомощь рядом;
- «напомни выпить таблетку в 9» — предлагает задачу и добавляет её после кнопки «Добавить»;
- принимает геопозицию и сохраняет её как адрес — тот же профиль, что и в миниаппе;
- в назначенное время напоминает о задачах из «Задач на сегодня» с кнопками «Сделано» и «Напомнить через 15 минут».

Когда бот включён, миниапп определяет пользователя только по подписанным данным MAX (`initData`),
заголовок `X-User-Id` от клиента не принимается. Без бота (разработка) — пользователь `demo`.

## Деплой на сервер

```bash
cd frontend && npm install && npm run build
```

```bash
cd backend && STATIC_DIR=../frontend/dist go run .
```

Бэк отдаёт и API, и собранный фронт на одном порту. Перед ним нужен HTTPS (например, Caddy или nginx с сертификатом на ваш домен).
Время задач и напоминаний считается по `APP_TIMEZONE` (по умолчанию Europe/Moscow), даже если сервер в UTC.
